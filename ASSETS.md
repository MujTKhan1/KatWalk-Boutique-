## Substitutions made

- **Photography.** No licensed fashion photography was supplied. The concept reference images are
  AI-generated and show illustrative people and products, so they were used only as visual direction. No
  model or product was cropped out of them. The three editorial panels are text-free vector illustrations,
  labelled on the page as placeholders.
- **Handbag.** The first version used a procedurally modelled 3D bag, which read as soft and undefined.
  Per review feedback, it is now a detailed static vector illustration, shown on an upright plane that
  always faces the camera. It is an illustration, not a photo of real merchandise. To use an approved product
  photo instead, export a transparent square PNG/WebP with the bag's base at the bottom edge and point
  `BAG_SRC` in `src/scene/Display.tsx` at it. A licensed GLB can replace the plane later if true 3D is wanted.

## Swapping in approved photography

1. Export at 4:5 (e.g. 1200×1500), WebP or AVIF, sRGB.
2. Update `src` and `alt` in `src/content/lookbook.ts`. The WebGL panels and HTML cards both read from it,
   so the handoff stays pixel-matched.
3. Re-render the static still: open `/?mode=immersive&capture` in dev, wait for the intro, then run
   `await __katwalkCapture()` in the console.
